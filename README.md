# Лабораторная работа №1 по Python: калькулятор и конвертер величин

## Введение
Данная утилита содержит в себе базовый калькулятр, поддерживающий фундаментальные арифметические операции, а также конвертер, предназначенный для перевода между единицами измерения различных физических величин.

В папке [src](./src) лежат файлы с реализацией зданной в лабораторной работе задачи. Точкой входа в программу является [main.py](./src/main.py) в этой папке. Кроме того, в ней лежит папка toolkit, в которой расположено вычислиительное ядро [kernel.py](./src/toolkit/kernel.py), файл констант [constants.py](./src/toolkit/constants.py), файл ошибок [errors.py](./src/toolkit/errors.py), файл обработки команд [__main__.py](./src/toolkit/__main__.py) и [__init__.py](./src/toolkit/__init__.py). Тесты калькулятора, конвертера и коммандной оболочки утилиты демонмтрируются в папке tests.

## Правила пользования 

Через терминал или командную строку необходимо открыть папку src. Возможные команды: python -m toolkit calc "ВЫРАЖЕНИЕ" - калькулятор, python -m toolkit convert "ЗНАЧЕНИЕ" --from "ЕД.ИЗМ.1" --to "ЕД.ИЗМ.2" - конвертер, python -m toolkit --help - справка.
Для начала работы необходимо выполнить cd src, а затем запускать указанные выше команды. 
Калькулятор обрабатывает операторы +,-,/,* и операнды представленные числами, причем положительные числа могут быть представлены со впередиидущим знаком "+" и без него, отрицательные же только с впередиидущим минусом ("-"). Поддерживаются нецелочисленные значения.Выражение калькулятора пишется в кавычках(как указано выше), скобки внутри выражения калькулятор не поддерживает.
 Аргументы конвертера же записываются без кавычек. Конвертер поддерживает длину, массу, темературу в следующих обозначениях соответственно - mm,cm,m,km (длина);g,kg (масса);k,f,c(температура). Поддерживаются нецелочисленные значения. Перевод между единицами измеренеия различных параметров не возможен. Результат выводится в виде числа с плавающей точкой. 
 Команда --help (она же -h) выдает краткую справку об утилите.
